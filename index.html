Pandora, a home network check anyone can use

WinnerSmartHack 2026, R Systems challenge

Built over one hackathon weekend with my team for the brief “Secure Networks, Simply Explained”. Pandora finds the devices on a home network and the open ports each one exposes, explains every risk in plain Romanian and English, and proves each fix with a re-scan.

  • Co-owned the scanner and rules engine. Findings and scores come from fixed rules, never from an AI, so the same scan always gives the same result.
  • Matched the organisers' validation set exactly (24 of 24 findings, 8 of 8 scores), checked in CI on every pull request.
  • Built the before and after comparison that never reports a fake fix, the cleaning of untrusted text sent by devices, and the CI pipeline with tests on Linux and Windows plus secret scanning.
